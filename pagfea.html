css


Que es css? css es un lenguaje para estilizar y diseñar paginas web de html
El proposito es controlar la apariencia de estos mismos.
Como se aplica? se puede aplicar Externamente , es decir en una pagina aparte al html, internamente que es adentro de de una tag que es "style" y directamente en la linea de codigo.
Un selector es directamente los elementos del html que va a manipular el css.

mas tags


tag selector: selecciona todas las etiquetas de un mismo tipo, class selector: selecciona elementos que tengan una clase especifica, tag+class: selecciona solo ciertos elementos, ID selector: selecciona un solo elemento con un id especifico.

mas teoria

que es una clase? una clase es un atributo que se usa para agrupar multiples elementos para que compartan el mismo estilo.
un id es lo mismo solo que para un unico elemento.
se relacionan porque css usa ".class" para grupos y "#id" para uno especifico.
Content the text or image, Padding space inside the element, Border edge around the element, Margin space outside the element,
